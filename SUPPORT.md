# Support

Use GitHub issues for public support after removing private information.

Include:

- Router model.
- OpenWrt version.
- ARK Router version.
- Package manager: `apk` or `opkg`.
- LuCI theme.
- Optional modules installed.
- A clear description of the behavior.

Do not share:

- Router passwords.
- Wi-Fi passwords.
- Private backups.
- Private keys or certificates.
- Customer data.
- Full MAC address lists unless they are anonymized.
