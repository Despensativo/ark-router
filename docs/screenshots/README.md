Do not include screenshots that expose private IP addresses, MAC addresses, Wi-Fi passwords, customer names or private event information.

If screenshots are captured from a real router, hide or replace:

- WAN IP addresses;
- device MAC addresses;
- Wi-Fi keys;
- customer/event names;
- exact public IP or GPS/location hints.
