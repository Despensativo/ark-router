# Logs sanitizados do W6x — lote 027

Snapshot de logs disponíveis, somente leitura. IPs/MACs pseudonimizados; SSIDs, fingerprints e quadros Wi-Fi removidos. Não somar kernel/logread nem fragmentos sobrepostos de crash como incidentes distintos. Consulte [o relatório](../../batches/027-router-logs.md) para escopo, mecanismo das mensagens SQM e limitações.
