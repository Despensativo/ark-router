# Code of Conduct

This project follows a simple rule: be useful, respectful and specific.

## Expected behavior

- Explain problems clearly and kindly.
- Discuss technical choices with evidence.
- Respect maintainers' time and review decisions.
- Avoid sharing private router data, customer data or credentials.

## Unacceptable behavior

- Harassment, insults or personal attacks.
- Publishing credentials, private backups, private IP maps or Wi-Fi passwords.
- Repeatedly pushing unsafe network changes after maintainers reject them.

Maintainers may close issues, remove comments or block users who make the project unsafe or hostile.
